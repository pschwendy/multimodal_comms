# Collab-Overcooked

Collab-Overcooked evaluates natural-language coordination between agents in an
interactive cooking environment, including process-oriented collaboration
metrics as well as task completion.

- [Paper: *Collab-Overcooked: Benchmarking and Evaluating Large Language Models as Collaborative Agents*](https://aclanthology.org/2025.emnlp-main.249/)
- [Original benchmark README](ORIGINAL_README.md)
- [Monorepo experiment guide](../../../../experiments/collab_overcooked/README.md)

The original README is preserved verbatim. Its paths refer to the standalone
application layout; use the monorepo experiment guide for current commands.
