# COMMA

COMMA evaluates language-based collaboration between multimodal agents that
receive complementary information while solving interactive puzzles.

- [Published paper: *COMMA: A Communicative Multimodal Multi-Agent Benchmark*](https://openreview.net/forum?id=TIGQIem1na)
- [arXiv paper](https://arxiv.org/abs/2410.07553)
- [Original benchmark README](ORIGINAL_README.md)
- [Monorepo experiment guide](../../../../experiments/comma/README.md)

The original README is preserved verbatim. Its paths refer to the standalone
application layout; use the monorepo experiment guide for current commands.
