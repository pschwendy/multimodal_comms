# iAgents

iAgents evaluates autonomous collaboration when agents act for different users
and must communicate to resolve asymmetric information.

- [Paper: *Autonomous Agents for Collaborative Task under Information Asymmetry*](https://arxiv.org/abs/2406.14928)
- [Original benchmark README](ORIGINAL_README.md)
- [Monorepo experiment guide](../../../../experiments/iagents/README.md)

The original README is preserved verbatim. Its web-app, database, and shell
paths describe the standalone application; use the monorepo experiment guide
for current offline evaluation and application commands.
