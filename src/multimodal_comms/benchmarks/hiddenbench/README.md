# HiddenBench

HiddenBench evaluates whether a group of language-model agents can combine
information that is distributed across participants under the hidden-profile
paradigm.

- [Paper: *HiddenBench: Assessing Collective Reasoning in Multi-Agent LLMs via Hidden Profile Tasks*](https://arxiv.org/abs/2505.11556)
- [Original benchmark README](ORIGINAL_README.md)
- [Monorepo experiment guide](../../../../experiments/hiddenbench/README.md)

The original README is preserved verbatim. Its installation commands and paths
describe the standalone benchmark distribution; use the monorepo experiment
guide for commands that match this repository.
